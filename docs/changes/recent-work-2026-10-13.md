# 워크스페이스 최근 작업 5건

왼쪽 워크스페이스 목록에 접을 수 있는 최근 작업 5건을 추가했다. 워크스페이스명, 작업명, 시간, 에이전트 아이콘과 상태를 두 줄로 표시한다. 기존 워크스페이스 순서는 유지하며, 기존 완료 필터의 이름은 실제 의미에 맞춰 `미확인`으로 바꿨다.

작업 기록과 미확인 완료 알림을 분리했다. 완료를 확인해도 기록은 남고, 살아 있는 세션을 선택하면 해당 워크스페이스와 세션으로 이동한다. 닫거나 종료한 세션은 기록을 유지하되 자동으로 탭을 복원하거나 프로세스를 실행하지 않고 워크스페이스를 연다. 프로세스의 호스트·이름·생성 시각을 확인하므로 재사용된 숫자 ID만 보고 다른 세션으로 이동하지 않는다.

Send가 전달된 요청의 첫 번째 비어 있지 않은 줄을 최대 120자로 기록한다. 전체 요청이나 터미널 출력은 새 이력 파일에 저장하지 않는다. 직접 터미널에서 진행한 작업은 서버의 작업 시작·완료 이벤트와 세션 제목으로 기록하며, 초기 목록은 이미 알려진 활동 시각으로 채운다. 단순 조회나 출력 갱신으로 목록 순서가 계속 바뀌지 않는다. 작업명은 연필 버튼으로 수정할 수 있다.

최근 기록은 서버의 `.recent-work.json`에 원자적으로 저장하며 권한은 0600이다. Git에서 제외했다. 상태 메시지에 별도 버전 번호로 포함해 모든 기기와 재접속에 동기화한다. 확인·이름 수정·종료·서버 재시작 이후에도 최근 5건을 유지한다. 기록 저장 실패가 이미 전달된 명령을 전송 실패로 표시하거나 재실행하게 만들지 않도록 분리했다.

검증: 프런트엔드 200개, 백엔드 191개 테스트 통과(기존 1개 건너뜀), TypeScript 검사와 운영 빌드 통과. 두 인증 클라이언트의 기록·이름·확인 동기화, 5건 제한, 완료와 입력 전송의 경합, 오래된 응답, 종료·닫힌 탭, ID 재사용, 디스크 저장 실패를 다룬다. 실제 브라우저 화면 검증은 포함하지 않는다.

배포 전 노트북 커널은 모두 종료돼 있었지만 저장 전 편집본 6개가 남아 있었고, 원본 파일이 사라진 항목도 확인됐다. 편집본과 복구 체크포인트가 일치하는 것을 검증하고, 비공개 `.releases/recent-work-preflight-*`에 JSON 및 각각의 `.ipynb` 사본을 0600 권한으로 백업했다. 원본 파일은 저장하거나 복원하지 않았다. 현재 서버는 재시작하지 않았으며, 배포 도구의 저장 전 노트북 보호 조건도 유지한다. 편집본 처리에 대한 사용자 확인 후 서버 변경을 배포해야 한다.
