# 노트북 기능 점검 — 2026-09-14

임시 노트북과 자체 생성 커널을 사용해 검사했다. 사용자 셀은 실행하지 않았다.

## 재현하여 수정한 문제

| 문제 | 수정 | 반영 조건 |
|---|---|---|
| 자동 동기화 중 실행 버튼과 Ctrl/Cmd+S가 무시됨 | 사용자 요청을 즉시 접수하고 진행 중인 동기화 뒤에 실행·저장 | 화면 새로고침 |
| 최초 연결 실패 후 다시 시도할 수 없음 | 다시 연결 버튼 제공 | 화면 새로고침 |
| 연결 복구 후에도 통신 오류가 남음 | 통신 오류를 편집 충돌과 분리하고 정상 응답 시 해제 | 화면 새로고침 |
| 통신 실패한 초안이 추가 입력 없이 서버에 재전송되지 않음 | 정상 상태 조회 후 미전송 초안을 다시 동기화. 충돌과 실행 중 상태에서는 자동 덮어쓰지 않음 | 화면 새로고침 |
| 환경 검색 결과가 없을 때 아무 표시도 없음 | 일치하는 환경 없음 표시 | 화면 새로고침 |
| 사용자가 중단한 실행을 일반 실행 오류로 표시 | 의도적 중단과 셀 오류 구분 | 서버 재시작 |
| 환경 연결 실패 메시지가 항상 서버 기본 Python을 가리킴 | 선택한 환경 이름과 실제 Python 경로 안내 | 서버 재시작 |
| 커널 목록 조회 때 전체 노트북을 JSON으로 만든 뒤 버림 | 목록에는 메타데이터만 직렬화 | 서버 재시작 |

화면 변경은 반영한다. 현재 연결된 사용자 커널이 있으므로 이번 점검에서는 서버를 재시작하지 않는다. 서버 변경 세 가지는 검증 완료 상태이며 다음 승인된 재시작에 적용된다.

## 검증

- 백엔드 106개 통과, 기존 브라우저 선택 테스트 1개 건너뜀.
- 프런트엔드 63개 통과.
- 브라우저에서 최초 연결 실패→재시도, 동기화 요청을 1.5초 지연한 상태에서 셀 실행·Ctrl+S, 빈 환경 검색을 검증.
- 기존 테스트로 실제 커널 연결·변수 공유·중단·재시작·환경 변경 확인, 외부 파일 저장 충돌·초안 복구·출력 제한을 검사.

## 다음 개선 우선순위

1. 환경의 ipykernel 설치 여부와 Python 버전 사전 표시. 현재는 연결할 때 검증하므로 이름만 보고 실행 가능 여부를 알 수 없다.
2. 셀 순서 이동·중간 삽입·유형 변경과 출력 접기·지우기. 현재는 추가·삭제·실행 위주다.
3. 큰 노트북의 보이는 셀만 편집기 생성. 현재는 모든 셀에 편집기를 생성하여 셀이 많으면 화면 부하가 커질 수 있다. 이 점검에서 대용량 성능 수치는 측정하지 않았다.
4. 언어 서버 기반 완성·도움말과 대화형 위젯. 현재 편집기는 문법 강조·검색·기본 편집 기능을 제공하며 JupyterLab 전체 기능을 대체하지 않는다.
