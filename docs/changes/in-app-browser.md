# 인앱 웹 탭

상단 **◎ 웹** 버튼으로 웹 탭을 열고 주소를 입력한다. 터미널과 문서의 일반 HTTP/HTTPS 링크도 해당 워크스페이스의 웹 탭으로 열린다. 수정 키를 누른 링크 클릭은 기존 외부 브라우저 동작을 유지한다.

- 주소 입력, 주소창 방문 이력의 이전·다음, 새로고침, 외부 브라우저 열기를 제공한다.
- 웹 탭도 파일·터미널과 함께 순서를 바꾸거나 화면을 분할할 수 있다.
- 탭과 워크스페이스 전환 및 분할 변경 시 기존 iframe을 유지하므로 페이지 내부 입력과 이동 상태가 유지된다. 탭을 닫으면 페이지도 해제된다.
- 앱을 새로고침하면 워크스페이스별 웹 탭, 주소창 이력, 분할 배치를 복원한다. 페이지 내부 입력 내용은 새로고침을 넘어 저장하지 않는다.

## 지원 범위

웹 탭은 iframe 기반 미리보기다. 사이트가 [CSP frame-ancestors](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors) 또는 X-Frame-Options로 삽입을 차단하면 표시할 수 없다. 외부 페이지는 앱과 분리된 sandbox에서 실행하며, 로그인·저장소·일부 네트워크 요청을 사용하는 사이트는 정상 동작하지 않을 수 있다. 이 경우 주소창 옆 **↗**로 외부 브라우저에서 연다. 보안 헤더를 제거하거나 사이트를 프록시하지 않는다.

외부 페이지 내부에서 이동한 주소는 앱에서 읽을 수 없다. 주소창의 이전·다음과 새로고침 후 복원은 **직접 입력하거나 링크로 연 주소**를 기준으로 한다. 외부 열기도 주소창의 주소를 사용한다. 관련 제약은 [MDN iframe 문서](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)를 참고한다.

## 검증

- 프런트엔드 테스트 48개 및 TypeScript/Vite 빌드 통과.
- 격리된 브라우저 검사: 문서·터미널 링크, 페이지 입력과 내부 이동 유지, 탭·워크스페이스·분할 전환, 주소 이력과 배치 복원, URL 검증, sandbox, 차단된 삽입의 외부 열기, 탭 닫기.
- 기존 분할 화면 회귀 검사: 17개 세션 표시, 복수 터미널, PDF·파일 슬라이더, 분할 비율과 배치 복원.
