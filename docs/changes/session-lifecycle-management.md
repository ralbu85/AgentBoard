# 상태와 세션 관리 개선

## 상태·알림

- 서버 연결과 에이전트 작업 상태를 분리했다. 서버/원격 머신 연결이 끊기면 마지막 작업 상태를 보존하고 `연결 끊김`을 표시한다. 원격 접속 종료를 프로세스 종료로 취급하지 않는다.
- 브라우저 재연결 시 전체 세션 메타데이터를 하나의 스냅샷으로 전달한다. 개별 생성 이벤트로 상태를 초기화하던 경로를 없앴다.
- 완료 이벤트 ID를 세션별로 브라우저 저장소에 보관한다(최근 100개). 확인 후 재연결하거나 같은 이벤트가 늦게 도착해도 알림을 다시 만들지 않는다. 이미 관찰했던 세션에서 연결 중단 중 완료된 새 이벤트는 스냅샷 비교로 찾는다. 최초 접속에서 과거 완료 이벤트는 알림 없이 기준값으로 등록한다.
- 원격 에이전트의 재연결 재전송에도 완료 ID, 자동 제목, 마지막 출력 변화 시각을 포함한다.
- 출력 변화 시각은 실제 관측이 시작된 이후부터 기록한다. 시각이 오래됐다는 사실만으로 멈춘 작업이라고 판단하지 않는다. 작업 상태 자체는 여전히 터미널 출력 기반 추정이다.

## 세션 관리

상단 `세션 관리`에서 전체·실행 중·종료됨·숨김·미연결 항목을 확인한다. 이름, 경로, 머신, tmux 이름, 프로세스로 검색할 수 있다.

- 각 세션에 자동 제목, 머신, tmux 이름, 작업 폴더, 프로세스, 상태, 마지막 출력 변화 시각을 표시한다.
- `숨김`은 이 브라우저의 워크스페이스 목록과 터미널 탭에서만 감춘다. 프로세스와 파일 탭은 유지한다. `숨김 해제` 또는 `열기`로 복원한다.
- `종료`는 작업 이름·머신·폴더를 표시하는 확인을 거친다. 로컬 종료는 tmux 프로세스 종료를 확인한 뒤 성공으로 처리하며, 실패하면 작업 중 상태를 유지한다. 원격 동작은 머신의 상태 이벤트로 확인한다.
- `기록 제거`는 종료된 세션용이다. 서버도 실행 중인 세션의 제거를 거절한다. 문서 파일은 삭제하지 않는다.
- `미연결`은 이 컴퓨터의 관리되지 않은 tmux 세션 목록이며 새로고침과 연결을 지원한다. 같은 세션에 대한 중복 연결 요청은 하나의 기존 세션으로 합친다.

원격 머신에는 갱신된 에이전트 코드가 적용되어야 새 완료 메타데이터 재전송을 지원한다. 숨김과 알림 확인 기록은 브라우저별이며 여러 기기 간에 동기화하지 않는다.

## 검증

- 프런트엔드: 완료 이벤트 100회 중복·이전 이벤트 재전송·재연결 스냅샷·중단 중 새 완료·연결 상태·숨김/복원 회귀 검사.
- 백엔드: 종료 실패, 실행 중 기록 제거 거절, 중복 연결, 원격 재전송 메타데이터, 2시간 분량의 가상 시간으로 동일 출력 재표시 검사.
- 격리 브라우저: 실제 렌더링된 관리 화면의 검색·분류·숨김/복원·확인 취소/승인·모바일 폭 검사. 종료 요청은 모의 API만 사용했다.
- 기존 17개 세션 표시, PDF/파일 슬라이더, 복수 터미널과 분할 배치 회귀 검사.

가상 시간 검사는 실제 에이전트를 두 시간 실행한 결과가 아니다. 실제 작업·네트워크 환경에서의 장시간 관측은 계속 필요하다.
