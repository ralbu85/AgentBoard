# 세션 전환 후 최신 출력 표시

터미널 인스턴스를 재사용하면서 이전 스크롤 위치를 그대로 유지했고, 모바일에서는 DOM을 다시 붙일 때 위치가 초기화될 수도 있었다. 최신 화면을 받아도 이를 과거 내용을 읽는 상태로 판단해 반영을 보류했다. 이전 화면의 크기 조절 콜백이 뒤늦게 실행되면 이전 읽기 위치를 복원하는 경합도 있었다.

세션을 새로 표시할 때는 보류된 출력부터 반영하고 최신 위치로 이동한 뒤, 서버에 최신 화면을 요청한다. 처음 도착한 화면도 최신 위치를 따른다. 사용자가 휠·터치·스크롤바·페이지 이동·검색으로 읽기를 시작하면 이 동작을 해제해 현재 읽는 위치를 유지한다.

전환 때마다 구분 값을 바꿔 이전 화면의 비동기 스크롤 복원이 새 화면에 적용되지 않게 했다. 화면에서 떠난 터미널 DOM은 분리하고, 다른 분할창으로 이동한 터미널을 뒤늦은 정리 작업이 제거하지 않도록 현재 소유 컨테이너도 확인한다. 높이가 낮은 데스크톱 분할창은 xterm 내부 스크롤과 바깥 스크롤을 함께 내려 마지막 출력 줄까지 표시한다.

프런트엔드 180개 테스트 및 TypeScript·운영 빌드 통과. 추가한 7개 회귀 테스트는 캐시된 세션 재진입, 보류된 출력 적용, 모바일 DOM 위치 초기화, 이전 크기 조절 콜백, 읽기 제스처 우선 처리, 분할창 소유권과 낮은 창 높이를 다룬다. 실제 xterm 코어와 모바일 DOM 경로를 검사했으며, 실제 브라우저·iPhone 화면 검증은 포함하지 않는다. 서버 코드는 변경하지 않았다.
