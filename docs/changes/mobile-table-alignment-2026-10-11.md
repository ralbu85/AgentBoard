# 모바일 터미널 표 정렬

표의 줄바꿈과 여백은 터미널 문자 폭으로 계산했지만, 모바일 DOM은 일반 텍스트로 표시했다. 내장 D2Coding 글꼴에 없는 이모지 등은 기기의 대체 글꼴로 표시되므로 실제 글자 폭이 계산과 달라질 수 있었다. 화면에 들어가는 작은 표는 원본의 열 여백이 불균일해도 재배치하지 않았다.

표 행에만 실제 측정한 영문 한 칸 너비를 사용하는 CSS grid를 적용했다. ANSI 스타일과 링크를 유지하면서 한글·기호·이모지의 다음 글자 위치를 터미널 열에 고정한다. 결합 문자와 이모지 조합은 한 덩어리로 유지한다. 표의 기기별 줄바꿈 이후 브라우저가 다시 줄을 접지 않으며, 글꼴 로딩·글자 크기 변경 시 같은 DOM의 칸 너비를 갱신한다. 원래 여백이 어긋난 작은 표와 Markdown 표도 열 너비를 맞춘다.

일반 문장의 표시 경로, 모바일 글자 크기, 네이티브 스크롤·선택 및 원문 복사 방식은 유지한다. 새 텍스트 노드 구조에서도 부분 복사·검색·링크와 변경 없는 행의 재사용을 검사했다.

검증: 프런트엔드 185개 테스트, TypeScript 검사, 운영 빌드 통과. 회귀 테스트 5개를 추가했다. 별도의 합성 브라우저 시나리오에는 화면 너비 390/430/844px와 글자 크기 12/13px에서 열 경계·행 높이·가로 넘침 검사를 추가했다. 이 환경에서는 안전한 브라우저 실행 환경이 준비되지 않아 해당 브라우저 검사와 실제 iPhone 검증은 실행하지 않았다. 서버·PTY 코드는 변경하지 않았으며 프런트엔드만 배포한다.
